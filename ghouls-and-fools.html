01

My contribution

Ghouls’n’Fools was my first big team project. I was the main developer, focusing on the game loop, lobby, input and movement, and on turning our designers’ prototypes into one game.

02

From separate prototypes to one game

Our designers built mechanics fast, as standalone prototypes. They worked on their own, but not together: lobby joining, colour assignment and game state all lived in one long Update() that checked for changes every frame. I connected each prototype to the rest of the game and moved the game flow to events and observers. Players joining, win and loss checks and the ghost counter now react when something happens, instead of polling every frame.

03

An experiment that didn’t ship

Unity’s spotlights didn’t give us the flashlight look we wanted, so I wrote flashlights from scratch in a custom HLSL shader, fed with each flashlight’s position and direction. It worked, but it was complex, so we went with spotlights cranked up instead. Simpler won.

04

Looking back

I also led the team. Next time, I’d set up code reviews and coding conventions from day one, and rebuild the enemy AI as a state machine or behaviour tree.
