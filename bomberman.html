PROJECT 05 / C++20 · SDL3 · CUSTOM ENGINE

Bomberman.

Classic Bomberman across Solo, Co-op and PvP, running on a 2D engine I built myself in C++20 on SDL3.

MY ROLE
Engine & gameplay programmer
TEAM
Solo project
PRODUCTION
1 semester
View source ↗

01

My contribution

I built both the engine and the game. Starting from the Minigin framework, I added systems for scenes, components, input, audio, collisions, events and save data.

02

Audio on its own thread

Sound requests go into a queue protected by a mutex and a condition variable, and a worker thread plays them, so the game never waits on audio. The sound system sits behind a service locator, with a silent default and a logging wrapper for debugging.

03

A stack for every screen

Title, menus, gameplay, game over and the leaderboard run on a stack of game states. Push puts a screen on top and keeps the one below alive, Pop returns to it exactly as it was, and transitions are queued instead of applied mid-frame.

04

A leaderboard with fairy dust

Every score is a multiple of 100, so I store score ÷ 100 in 16 bits instead of the full score in 32. Each entry shrinks from 7 bytes to 5. Does it matter on modern hardware? Not at all. Did I enjoy it? Very much.

05

Looking back

The final stretch was rushed, so code cleanup and consistency come first. After that: faster component lookups and a fixed timestep.
